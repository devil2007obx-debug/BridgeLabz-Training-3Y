1. Difference between Frontend, Backend and Full-Stack Development

Ans. Web development is mainly divided into three parts: frontend, backend and full-stack development.

Frontend Development:

Frontend is the part of a website which users can see and interact with directly. It includes designing webpages, buttons, menus, images, and layouts.

Technologies used: HTML, CSS, JavaScript, React etc.

Example:

In an online shopping website, the product page, search bar, images and add to cart button are frontend parts.

Backend Development:

Backend is the server-side part of a website. It manages the logic, database connection, user authentication and processing of requests.

Technologies used: Python, Java, Node.js, PHP etc.

Example:

When a user places an order on Amazon, backend processes the order and saves information in the database.

Full-Stack Development:

A full-stack developer works on both frontend and backend parts of an application.

Example:

A developer who creates the complete shopping website including user interface, server and database is called a full-stack developer.

3. How Browser Requests and Displays a Web Page

Ans. When a user enters a website address in the browser, the following steps happen:

   1. User enters URL in browser.

   2. Browser sends request to web server.

   3. Web server processes the request.

   4. Server collects data from database if required.

   5. Server sends HTML, CSS and JavaScript files back.

   6. Browser reads files and displays webpage.

8. Difference Between Static and Dynamic Websites
Static Website:

A static website contains fixed content. The same information is shown to every user.

Features:

Simple and fast
No database required
Mostly HTML and CSS based

Example:
Personal portfolio website.

Dynamic Website:

A dynamic website changes content according to users and database information.

Features:

More interactive
Uses backend and database
Content can change automatically

Example:
Amazon, Facebook and online banking websites.
