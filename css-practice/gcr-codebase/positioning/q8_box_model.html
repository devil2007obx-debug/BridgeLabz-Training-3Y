Box Model Exploration

The Four Layers

Content

Content — the actual text or elements inside the box.

Padding — space between content and border.

Border — the visible edge surrounding the padding.

Margin — transparent space outside the border, separating this box from others.

content-box vs border-box

content-box
width: 200px applies only to the content; padding and border are added on top, so the box renders wider than 200px total.
border-box
width: 200px includes padding and border, so the box stays exactly 200px wide overall.
