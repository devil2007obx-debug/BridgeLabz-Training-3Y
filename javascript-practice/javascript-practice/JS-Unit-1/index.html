JavaScript Assignment 1 (Lectures 1-3)

Ten programs, each with its own HTML page and .js file. Open a question to run it.

Multi-Type Data SummaryDifferent data types identified with typeof and Array.isArray(), printed by one console.table(). Q3. Monthly Expense TrackerTotal, average and final amount after 10% tax. Results update as you type. Q4. Academic Performance EvaluatorAverage, percentage and result for 5 subjects (any mark below 35 means Detained). Q5. Weather Activity PlannerSuggests an activity from temperature, rain and wind speed. Q6. Progressive Discount System25% from 10000, 15% from 5000, 5% from 2000, otherwise none. Q7. Smart Guessing GameGuess the secret number between 1 and 50. Q8. Employee Salary Projection5-year salary projection using a for loop. Q9. Random Math Quiz GeneratorRandom arithmetic questions solved with a switch statement. Q10. Citizen Eligibility ValidatorChecks vote, drive and passport eligibility from age and citizenship.
